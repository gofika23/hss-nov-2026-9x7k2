# HSS hype page

A small static GitHub Pages site for the Hardcore Superstar event.

## Publish on GitHub Pages
1. Upload `index.html`, `robots.txt`, and `README.md` to the repository root (not inside another folder).
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then Save.
5. Wait for GitHub Pages to publish the site.

`robots.txt` and the `noindex` meta tag ask search engines not to index the page. They do **not** make a public GitHub Pages site private or password-protected.

Music is played through YouTube's embedded player. YouTube may show branding, may block autoplay, and playback availability depends on the user's device/network. The volume dial on the intro is visual only; the visitor must raise their device volume manually.
